# Pen-Fight
A Pen-Fight Web Application to play with bots or Friends
Tried experimenting with the new, latest Gemini AI model, Argon 4.
Turns out it really made a pretty good web game even though I had to prompt and debug this thing using the prompts again and again multiple times.
I know its not easy for newer AI models for creating such a game with accurate physics, velocity and things, and am not criticizing it, it certainly did a really good job.
Note To Users/Developers: I may Acknowledge to y'all that this site is not made by my code, instead the entire thing was made by the AI Model (Since, I was trying to test its capabilities) even the bug fixes were done by the model, though I had to point out the bugs.
Certainly the Idea was from my and my friend's thought.
